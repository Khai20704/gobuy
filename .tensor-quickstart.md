# ⚡️ REST API Quickstart Guide

> 🚧 This API is in Alpha! Breaking changes may occur without warning!

Welcome to the REST API Quickstart Guide! This guide will help you get started with the Tensor API in your projects. Whether you're looking to integrate Marketplace Features, access our deep liquidity, or any other feature offered by Tensor, you'll find the essential information needed to begin here.

## API Key

> 🚧 If you are a large trader/market-maker or if you build a program for the public to use and believe you should be eligible for a Tensor API key, please fill out [this form](/page/tensor-api-form)

## Calling API Endpoints via UI

To first get used to our endpoints, you can make API calls directly from our Developer Hub! Just select the endpoint you are interested in, fill in your API key on the right side and the request variables on the left side and click on "Try it!".
